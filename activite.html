L’objectif est de comprendre que le produit de nombres positifs s’étend aux nombres relatifs : deux nombres de signes contraires donneront un produit négatif alors que deux nombres de même signe donneront un produit positif

Activité 2 : Signe d’un quotient

L’objectif est de déduire une règle sur le quotient de deux relatifs à partir du produit de deux nombres négatifs

  1. Compléter les produits suivants à l’aide de quotient

4×…=124 \times \ldots = 12 (−5)×…=130( - 5) \times \ldots = 130 8×…=(−16)8 \times \ldots = ( - 16) ….×(−3)=(−27)\ldots.\ \times ( - 3) = ( - 27)

  1. En déduire le résultat des calculs suivants

135−10−1−1135−3−5−2\frac{135}{- 10}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{- 1}{- 1}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{135}{- 3}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ - \frac{5}{- 2}\

Afficher la correction

  1. Le produit à trou a pour solution un quotient

  • Pour 4×…=12,4 \times \ldots = 12,\ on cherche une valeur positive vérifiant 124\frac{12}{4}. La solution est 3

  • Pour (−5)×…=130( - 5) \times \ldots = 130, on cherche une solution négative vérifiant 130−5\frac{130}{- 5} or 5×26=1305 \times 26 = 130.

La solution est 130−5=−26\frac{130}{- 5} = - 26

  • Pour 8×…=(−16),8 \times \ldots = ( - 16), la solution est négative vaut −2- 2 mais aussi −162- \frac{16}{2}. Ainsi −162=−2- \frac{16}{2} = - 2

  • Pour ….×(−3)=(−27),\ldots.\ \times ( - 3) = ( - 27),\ la solution est positive est vaut 9 mais aussi −27−3\frac{- 27}{- 3} . Ainsi −27−3=9\frac{- 27}{- 3} = 9

On remarque que le quotient suit la même règle des signes que le produit !

135−10=−13.−1−1=1135−3=−(1353)=−45−5−2=−(5−2)=−(−2.5)=2.5\frac{135}{- 10} = - 13.\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{- 1}{- 1} = 1\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{135}{- 3} = - \left( \frac{135}{3} \right) = - 45\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ - \frac{5}{- 2} = - \left( \frac{5}{- 2} \right) = - ( - 2.5) = 2.5\

L’objectif est de comprendre que le quotient de nombres positifs s’étend aux nombres relatifs : deux nombres de signes contraires donneront un quotient négatif alors que deux nombres de même signe donneront un quotient positif
