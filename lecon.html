1. Somme et différences

Méthode

➕ Addition

✅ Même signe : J'additionne et je garde le signe.

Exemple :

  • (+3) + (+5) = +8

  • (−4) + (−6) = −10

✅ Signes différents : Je fais la différence et je garde le signe du plus éloigné de 0.

Exemple :

  • (+9) + (−4) = +5

  • (−8) + (+3) = −5

Remarque

On peut raisonner avec les gains (+) et les pertes (−) comme pour l’argent

➖ Soustraction

✅ Je transforme en addition de l'opposé.

Exemple :

  • (+7) − (+2) = (+7) + (−2) = +5

  • (−5) − (−3) = (−5) + (+3) = −2

Exemple :

A=(−3)+(−9)−(−15)−(+14)A = ( - 3) + ( - 9) - ( - 15) - ( + 14)

On transforme les soustractions en additions

A=(−3)+(−9)+(+15)+(−14)A = ( - 3) + ( - 9) + ( + 15) + ( - 14)

On regroupe par signes

A=(−3)+(−9)+(−14)+(+15)A = ( - 3) + ( - 9) + ( - 14) + ( + 15)

On calcule

A=(−26)+(+15)A = ( - 26) + ( + 15)

A=(−11)A = ( - 11)

Simplification de l’écriture

Le signe + des nombres positifs n’étant pas obligatoire , en pratique, on peut procéder selon la règle des signes suivante

✅ « +(−+ \ (\ - » équivaut à « −-» 

✅ « −(+- \ (\ + » équivaut à « −-» 

✅ « +(++ \ (\ + » équivaut à « ++»

Exemple :

On regroupe par opérations en raisonnant comme pour la perte et le gain d’argent

A=−3−9−14+15=−26+15A = - 3 - 9 - 14 + 15 = - 26 + 15

Opposés d’un nombre relatif

✅Dire que deux nombres sont opposés revient dire que leur somme vaut 0.

✅En pratique, deux nombres opposés sont de signes contraires et ont la même distance à 0

Exemple :

2. Produit de nombres relatifs

✖️ Méthode

Pour multiplier deux nombres relatifs, on effectue deux étapes.

  • On applique la propriété sur la règle des signes :

    • si les deux nombres ont le même signe, alors le résultat est positif :

+×+→++ \times + \ \rightarrow \ + −×−→+- \times - \ \rightarrow \ +

  • si les deux nombres sont de signes contraires, alors le résultat est négatif

+×−→−+ \times - \ \rightarrow \ - −×+→−- \times + \ \rightarrow \ -

  • On multiplie leur distance à 0 (En pratique : sans les signes).

4. Signe d’une suite de produits et divisions

Méthode

Dans une série de produits et quotients, le résultat est

  • positif lorsque le nombre de nombres négatifs est pair

  • négatif lorsque le nombre de nombres négatifs est impair

Les nombres positifs n'influencent pas le signe final

Démonstration :

Dans une expression composée de quotient et produit, les positifs n’impactent pas le résultats (confer règle des signes), seuls les négatifs peuvent. Or deux négatifs donnent un positif, si il y a un nombre pair de négatifs le résultats seront donc positifs, sinon (c’est-à-dire un nombre impair de négatifs), le résultat sera négatif

(–4)×(+3)×(–2)×(–10)=–(4×3×2×40)=−240(–4) \times \ ( + 3) \times (–2) \times (–10) = \ \ –(4 \times 3 \times 2 \times 40) = - 240
